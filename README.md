# campb3c7.github.io

A personal site that hosts a collection of independent mini-apps. The
homepage is a hub; each app lives in its own folder under `apps/` and is
fully self-contained.

**To add an app:** drop a folder with an `index.html` into `apps/` and add
one entry to `apps/manifest.js`. Full details (including rules for AI
assistants) are in [CLAUDE.md](CLAUDE.md).

Current apps:

- **PA Study App** (`apps/study/`) — flashcards, quizzes, and study tools.
- **Sample App** (`apps/sample/`) — a minimal example of the app pattern.
