Command dictionary & how it works

The idea. Your fighter is the O. It only does what your program says. The code you write is your think() — the game runs it over and over to ask "what now?". You answer by calling commands like move() and attack().

Clock & ticks. Every command costs ticks. Your brain runs at a clock speed (ticks per second), so the more your think() does, the longer that decision takes and the slower you react. Thinking is cheap; moving is expensive — so spamming heavy logic makes you sluggish.

sense the world~5 ticks
logic / face / a line of code~1 tick
attack~20 ticks
block~15 ticks
move (you)~50 ticks
move (foe)~100 ticks

You have half the move cost of the foe, so you decide & reposition about twice as often — pure dodging keeps you safe. But you have less HP and your hits are weaker; the foe is slow but hits like a truck. Get greedy and one clean hit hurts.

Syntax basics (C / JavaScript style)
// a comment — notes for you, ignored by the game.
let d = distanceToOpponent(); — store a value in a name.
if (d < 4) { attack(); } — do something only when a test is true.
else { moveToward(opponentPosition()); } — otherwise, do this instead.
state.count = (state.count || 0) + 1; — state remembers things between ticks.
Sensing — ask about the world
myPosition()
Where you are. Returns {x, y}.
opponentPosition()
Where the nearest foe is. Returns {x, y} (or null if none).
opponentAngle()
Direction to the foe in degrees, 0–360 — 0 = up, 90 = right, clockwise.
distanceToOpponent()
How far away the foe is, in arena units.
opponentIsAttacking()
true while the foe is mid-swing — your cue to block() or dodge.
me()
Your own status: {x, y, hp, facing, alive}.
arena
The field size: {width, height}.
Acting — tell yourself what to do
move(direction)
Walk that way. direction is a word — "up" "down" "left" "right" "upleft" "upright" "downleft" "downright" — or an angle in degrees (snaps to the 8 directions). You keep going until you change it.
move("upleft");   or   move(90);
moveToward(target)
Walk toward a point or angle. target is a {x,y} or a number.
moveToward(opponentPosition());
moveAway(target)
Walk away from a point or angle (kiting / retreat).
dodge(side)
Sidestep relative to the foe. side is "left", "right", or leave it empty to auto-zigzag.
dodge();   or   dodge("left");
stop()
Stand still.
lookAt(target)
Face a point or angle. Your swing lands where you're facing, so aim before you attack.
attack()
Swing your sword / in a short, narrow arc in front of you. Has a cooldown, so timing matters.
block()
Raise a guard for a moment. A blocked hit deals no damage and staggers the attacker — your opening to counter. You can't move while blocking, and it has a cooldown, so time it as the foe commits.
Helpers
state
An object that survives between ticks — your memory (e.g. state.mode).
dist(a, b)
Distance between two {x,y} points.
angleTo(from, to)
Angle from one point to another, 0–360.
log(...)
Print to the console below — handy for debugging.
