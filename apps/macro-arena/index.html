API reference & how it works

Your O only does what your code says. The code below is your think() — it runs ~10×/sec. Heavier thinking costs reaction time: the more work per tick, the later your moves land. Keep it tight to out-react the foe.

sensing

myPosition() → {x, y}

opponentPosition() → {x, y} of nearest foe

opponentAngle() → angle to foe, 0–360° (0=up, 90=right, clockwise)

distanceToOpponent() → number (arena units)

me() → {x, y, hp, facing, alive}

arena → {width, height}

acting

move(dir) — "up" "down" "left" "right" "upleft" "upright" "downleft" "downright", or an angle in degrees (snaps to 8-way)

moveToward(target) — target is a {x,y} or an angle

moveAway(target) — flee from a point/angle

stop() — stand still

lookAt(target) — face a point or angle (aims your swing)

attack() — swing your sword / (has a cooldown)

helpers

state — an object that persists between ticks (your memory)

dist(a, b), angleTo(from, to), log(...)
